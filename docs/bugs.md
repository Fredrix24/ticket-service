# Найденные дефекты

## BUG-1: Редактирование закрытой заявки
- **Суть:** Метод `PATCH /api/tickets/{id}` позволял изменять данные заявки в статусах `RESOLVED` и `CANCELLED`. Это нарушает правило неизменности закрытых заявок.
- **Шаги:**
    1. Создать заявку.
    2. Перевести в `IN_PROGRESS`, затем в `RESOLVED`.
    3. Вызвать `PATCH /api/tickets/{id}` с `{"description": "Новое описание"}`.
- **Факт:** 200 OK, данные меняются.
- **Ожидание:** 409 Conflict, данные не меняются.
- **Статус:** Исправлен.
- **Регрессия:** `regression_UpdateClosedTicket_Returns409`.
