# Отчет

## Выполненные задачи
1. **Аналитика:** 7 пользовательских историй с критериями приемки, ER-диаграмма, спецификация API.
2. **Java-функционал:** CRUD заявок, бизнес-правила переходов статусов, история изменений, фильтрация и пагинация.
3. **Kotlin-интеграция:** Сервис статистики с `data class` и nullable-типами, взаимодействие через Java-интерфейс (порт).
4. **Тестирование:** 10 модульных, 6 интеграционных, 2 E2E и 1 регрессионный тест (всего 23 теста).
5. **DevOps:** Многоэтапный Dockerfile, Docker Compose с healthcheck, скрипты бэкапа/восстановления.
6. **CI/CD:** Пайплайн GitHub Actions с self-hosted runner (WSL), публикация в GHCR, деплой и health check, отдельный workflow для отката.

## Найденные дефекты
- **BUG-1:** Редактирование закрытой заявки (исправлено, добавлен регрессионный тест).

## Ограничения решения
- Аутентификация/авторизация не реализованы.
- Приложение разворачивается в единственном экземпляре (без горизонтального масштабирования).
- Мониторинг ограничен health check (Actuator).
